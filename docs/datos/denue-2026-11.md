# DENUE del INEGI como fuente de negocios (nov 2026)

Consultado el **11 de noviembre de 2026**. El [DENUE](https://www.inegi.org.mx/servicios/api_denue.html) (Directorio Estadístico Nacional de Unidades Económicas) es el censo oficial de negocios del INEGI: nombre, razón social, giro (SCIAN), dirección, coordenadas y, cuando el negocio los dio, teléfono, correo y web. Son datos abiertos.

## Cómo se bajó

- La API pide un token gratis (formulario en `https://www.inegi.org.mx/app/api/denue/tokenVerify/tokenverify.html`; en la página de la API está escondido tras el "aquí" del parámetro Token). **El token no va en el repo.**
- Todo el municipio, de 1,000 en 1,000: `https://www.inegi.org.mx/app/api/denue/v1/consulta/BuscarAreaAct/22/017/0/0/0/0/0/0/0/0/<inicio>/<fin>/0/<token>` (Querétaro = 22, Tequisquiapan = 017). Salen **5,131 negocios**.
- De ahí, los 1,360 de giros turísticos están en [`denue-tequisquiapan-turismo-2026-11.csv`](denue-tequisquiapan-turismo-2026-11.csv). La columna `en_catalogo` es un cruce automático por nombre y distancia con falsos positivos (p. ej. "Habibi → Hotel Las Delicias"): no la uses sin revisar.

## Regla

tequis.travel y el PDF 2025 son de Turismo municipal y cuentan como **una** fuente. El DENUE es independiente: **DENUE + Turismo o + web propia = dos fuentes**, y con eso un negocio puede darse de alta (con `content_verified = false` si no hay web propia). El DENUE también desempata [CONFLICTO]s de teléfono o calle. Cuidado: lo reporta el propio negocio y puede ser viejo (`alta_denue` 2010-07 es la carga inicial del censo); sus webs y correos tienen erratas y dominios secuestrados (`lacazonatequisquiapan.com`, `txtur.com` en TX Ecotours, `regalodelalma.com.mx` hoy redirige a una refaccionaria). **Solo DENUE no basta** para dar de alta.
